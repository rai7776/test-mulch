# Recall Lab — 英単語の記憶実験ツール

Smart Readerの学習画面とは独立した、ブラウザ上の英単語暗記カード実験です。

## 開く
- GitHub Pages: https://rai7776.github.io/test-mulch/recall-lab/
- 実装: `recall-lab/index.html`（外部ライブラリなし）

## 使い方
1. 「登録・データ」で `abandon[TAB]放棄する` のような行を貼り付ける（カンマ区切り・縦棒区切りも対応）。
2. 英単語を見て意味を想起し、「答えを見る」→「思い出せた／思い出せなかった」を選ぶ。
3. 最初に正答するまでにかかった経過時間と試行回数を保存。
4. 最初の正答後に、試行回数の区分内で均等になるよう3分・10分・30分間隔へランダム割当。
5. 短期再確認後は1日・7日・30日・90日後の確認テストを予約。
6. 「単語一覧」で初回習得時間の長い順／試行回数の多い順等に並び替える。
7. 「実験結果」で各条件の測定数、正答率を確認。
8. 「登録・データ」からJSONまたはCSVを保存する。JSONは再インポートも可能。

## ChatGPTで分析する
「登録・データ」→「全記録をJSON保存」で生成したファイルをチャットに添付すると、回答履歴から条件間の保持率や初回習得速度との関係を分析できます。「要約をコピー」ならレポートをそのままチャットへ貼り付けられます。

**重要**: 学習記録は利用中のブラウザのlocalStorageに保存されます。自動同期・サーバー送信・ChatGPTへの自動共有はありません。別端末で開いても別の記録になります。定期的にJSONをバックアップしてください。

## 実験上の注意
- 3・10・30分は仮説検証のための条件であり、最適間隔の既知の答えではありません。
- 「初回習得時間」はカード初回表示から最初の正答までの経過時間で、離席等も含まれ得ます。個々の回答にかけた時間は別途保存されます。
- 自己判定であること、予定より遅れて復習したこと、途中の確認テスト自体が記憶を強めることを分析時に考慮してください。
- 長期段階は固定チェックポイントを使って実験結果を比較する設計で、FSRSの個人最適化機能は未搭載です。
